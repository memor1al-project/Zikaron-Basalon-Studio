# Zikaron Basalon
The purpose of this application is to advance https://www.zikaronbasalon.com/ project to allow it to utilize AI and advanced agentic capabilities to scale up & automate the testimony collection, assisting for the buildup of the story told by the host and simplify and tutore the people hosting the events with building of the presentation narative and evening presentation.
The website will be in the same UX as the existing website but will offer the following advanced capabilities:

## Collection
 - AI assistant wizard based on the main testimony collection concepts to assist gathering and collecting the story using
   - platform for loading and collecting all the relevant resources (including using existing historical materials)
   - allow search, associate, connect and fuse materials for simplify the storybuilding  
   - exampe nerative that will guide the collection interview process
   - historical context assiatance (references and )
   - similar conceptiual stories to take ideas from
   
 
 ## Presentation:
  - AI assistant wizard & guideline for building a story
    - tutorial showcasing in simple and illustrative way existing stories as use case examples
    - wizard based on the main concepts to assist building the evening presentation
    - Leading steps based on the collected material to help build a presentation story & visualization
